# Security policy

MEOVV Mail handles credentials, private correspondence, and internet-facing
mail protocols. Please report suspected vulnerabilities privately.

## Supported versions

This repository is currently pre-1.0. Security fixes are applied to the latest
release and the `main` branch only. Older snapshots are not supported.

## Reporting a vulnerability

Use the repository's **Security → Report a vulnerability** form to open a
private GitHub Security Advisory. Do not include exploit details, credentials,
message contents, or customer information in a public issue.

Include the affected version or commit, deployment topology, reproduction
steps, expected impact, and any suggested mitigation. You should receive an
initial acknowledgement within three business days. Disclosure timing will be
coordinated after the report is validated and a remediation is available.

If private vulnerability reporting has not yet been enabled on the repository,
contact the repository owner privately and ask them to enable it; do not open a
public issue containing vulnerability details.

## Deployment reports

Configuration questions, spam-delivery problems, and ordinary operational
failures are not vulnerabilities. Remove domains, IP addresses, credentials,
email addresses, message bodies, and logs containing personal information
before sharing a diagnostic report.
